# Gavel — Առցանց աճուրդների կառավարման հարթակ
> Կուրսային աշխատանք / Course Work Project

## 1. Նախագծի նկարագրություն
**Gavel**-ը ժամանակակից առցանց աճուրդների կառավարման վեբ հարթակ է, որտեղ վաճառողները կարող են տեղադրել իրենց արժեքավոր իրերը (արվեստ, անտիկվարիատ, ժամացույցներ, գորգեր, զարդեր), իսկ գնորդները՝ մասնակցել աճուրդներին, ներկայացնել գնային առաջարկներ և հետևել աճուրդի ընթացքին:

Նախագիծը կառուցված է մաքուր, սեմանտիկ **HTML5 և CSS3** տեխնոլոգիաներով.
- **HTML ֆայլերում չկա ոչ մի `<style>` թեգ կամ inline `style="..."` ատրիբուտ:**
- **Բոլոր CSS ոճերը կազմակերպված են մեկ միասնական [`css/`](css/) թղթապանակում:**
- **Յուրաքանչյուր HTML էջ ունի իր առանձին CSS ֆայլը + ընդհանուր `common.css` ֆայլը:**
- **Բոլոր նկարները գտնվում են մեկ միասնական [`images/`](images/) թղթապանակում:**

## 5. Ինչու՞ կարող է կայքը չբացվել կամ խառնվել այլ համակարգչում (Հիմնական պատճառներն ու լուծումը)

Եթե ուրիշի համակարգչում կայքը բացելիս չեն երևում նկարները, չկա դիզայն կամ էջը ցույց է տալիս միայն սև-սպիտակ տեքստ, պատճառները հետևյալն են.

### 1-ին պատճառ (Ամենատարածվածը)՝ Բացել են ZIP ֆայլի միջից՝ առանց «Extract All» անելու
* **Ինչ է կատարվում.** Երբ նախագիծը ZIP արխիվով ուղարկում եք այլ համակարգիչ (օր.՝ Telegram-ով կամ mail-ով), և մյուս համակարգչում պարզապես երկու անգամ սեղմում են `.zip`-ի վրա ու ներսից բացում `index.html`-ը, Windows-ը ժամանակավոր բացում է **միայն այդ մեկ HTML ֆայլը** (`Temp` պանակում), իսկ `css/` և `images/` պանակները մնում են արխիվում: Արդյունքում բրաուզերը չի գտնում ոճերն ու նկարները:
* **Լուծումը.** Մյուս համակարգչում ZIP ֆայլի վրա սեղմել աջ քլիք -> **«Extract All...»** (կամ «Քաղել բոլորը» / «Извлечь все») -> բացել ստացված սովորական պանակը -> նոր միայն բացել `index.html`-ը:

### 2-րդ պատճառ՝ Ուղարկվել է միայն `index.html` ֆայլը (առանց `css/` և `images/` պանակների)
* **Ինչ է կատարվում.** Եթե ուղարկվել է միայն `index.html`-ը, բրաուզերը չունի CSS ֆայլերը և նկարները:
* **Լուծումը.** Պետք է տեղափոխել **ամբողջ նախագծի պանակը** (որի մեջ կան `index.html`, `css/` և `images/`):

### 3-րդ պատճառ՝ OneDrive-ի «Cloud-Only» (Файлы по запросу) կարգավիճակը
* **Ինչ է կատարվում.** Քանի որ աշխատանքը գտնվում է OneDrive պանակում, եթե ֆայլերի կողքին կա «ամպիկի» պատկերակ, ֆայլերը կարող են ֆիզիկապես բեռնված չլինել կոշտ սկավառակի վրա արխիվացնելու կամ պատճենելու պահին:
* **Լուծումը.** Պատճենելուց կամ ZIP անելուց առաջ աջ քլիք անել պանակի վրա -> **«Always keep on this device»** («Միշտ պահել այս սարքում»):

### 4-րդ պատճառ՝ Windows-ի արգելափակումը համացանցից ներբեռնված ZIP-ների համար (Mark of the Web)
* **Ինչ է կատարվում.** Որոշ համակարգիչներում (հատկապես համալսարանի կամ գրասենյակային) Windows-ը կարող է սահմանափակել ներբեռնված արխիվների ֆայլերի աշխատանքը:
* **Լուծումը.** Աջ քլիք ZIP ֆայլի վրա -> **Properties (Հատկություններ)** -> ներքևում նշել **«Unblock» (Разблокировать)** -> Apply -> ապա նոր քաղել (Extract All):
